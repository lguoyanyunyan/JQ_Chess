# 发布检查清单

更新时间：2026-04-29

本文记录 JavaFX 版发布前检查项和交付材料状态。构建产物位于 `JQJava/target/`，受 `.gitignore` 忽略，不应提交到版本库。

## 必做检查

在 `JQJava/` 目录执行：

```powershell
mvn -q test
```

期望结果：全部 JUnit 测试通过。

```powershell
mvn -q -DskipTests package
```

期望结果：生成主 jar 和运行时依赖目录。

## Windows app-image

在 `JQJava/` 目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\package-windows.ps1
```

期望输出：

```text
target\dist\windows\ZangJiuQi-Java
```

可执行文件：

```text
target\dist\windows\ZangJiuQi-Java\ZangJiuQi-Java.exe
```

脚本会先运行测试，再执行 Maven package 和 `jpackage`。脚本包含项目内路径校验，并会清理旧的打包输入目录和旧 app-image。

## Windows 安装包

可选执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\package-windows.ps1 -Installer
```

如果本机缺少安装包依赖，脚本会回退生成 app-image。
