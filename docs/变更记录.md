# 变更记录

本文记录工程实现、规则口径、构建环境和文档同步变更。规则原文以 [藏族久棋最新规则.pdf](藏族久棋最新规则.pdf) 为基线。

## 2026-05-06：传统获胜阵型选择驱动 v2

- 传统获胜阵型扩展为 `关闭` / `拉萨` / `金鱼`，竞技化模式继续归一为关闭。
- 新增 PDF 图17 原图确认的金鱼 14 子 offset 模板，允许旋转与镜像；金鱼可作为单独传统获胜阵型接入，但不宣称八吉祥整套制度已实现。
- 传统胜负和传统 AI 长期目标改为由前端选择驱动：选择 `拉萨` 只检查双门/三门拉萨，选择 `金鱼` 只检查金鱼，未选择的阵型不影响本局胜负或 AI 目标启发。
- core 静态模板扫描与 AI `PatternShape` 模板共用拉萨/金鱼资料；保留弱势方飞子临界保门胜口径。
- 更新 JavaFX 提示、运行说明、当前实现状态、规则覆盖表、路线图、架构说明和发布材料。

## 2026-04-30：传统获胜阵型 v1

- 将 JavaFX 版传统胜负配置调整为传统获胜阵型选择，v1 提供 `关闭` 与 `拉萨`。
- 传统基础模式下，形成双门拉萨或三门拉萨并完成补吃后，若形成方棋子更多、对方本手开始时尚未进入飞子阈值且结算后没有棋门，可按拉萨获胜阵型判形成方获胜；本手未新形成拉萨时，也会扫描强势方是否已静态保持完整拉萨。
- 新增传统飞子临界裁定：弱势方本手首次被吃到飞子阈值内时，若强势方本手未形成所选获胜阵型且弱势方仍有棋门，则判弱势方胜。
- 纯 Java AI 新增规则模式 profile 分流：竞技化 profile 继续偏重吃子、材料和即时战术；传统基础 profile 提高目标阵型进度、破坏棋门和飞子临界风险权重。
- 新增传统阵型 heuristic 扩展点，v1 接入拉萨目标启发，并抽出 `PatternShape` / `PatternShapeScanner` 模板底座；新增传统阵型模板资料文档，明确八吉祥、飞子阵型和让棋目标尚未进入默认 AI 启发；搜索框架仍为 `negamax + alpha-beta + transposition table`，不引入 MCTS。
- 收口 JavaFX 提示、运行说明、发布检查清单和状态文本测试，统一为“强方拉萨胜 / 弱方飞子临界保门胜”口径。
- 新增发布材料 v1、演示脚本 v1 和截图目录说明，用于 JavaFX 阶段性交付。
- `.jqj` 新增使用 `traditionalWinningPattern` 语义；旧 `traditionalWinMode=OFF` 可兼容读取，旧非关闭传统胜负方式会提示重新选择获胜阵型。
- 更新 UI 文案、状态摘要、规则覆盖表、路线图和 Java 版运行说明。

## 2026-04-22：竞技化 8x8 与 AI 非法着法修复

- 将棋盘尺寸抽为规则配置：传统基础规则保持 `14x14`，竞技化规则改为 `8x8`。
- WinForms 棋盘绘制、点击命中、行列编号、中心清空点、满盘判断、悔棋恢复和读档校验均改为按当前规则尺寸执行。
- AI 新增尺寸感知接口 `getAIMoveEx(..., boardSize, ...)`，旧 `getAIMove(...)` 保留为 `14x14` 兼容入口。
- C++ AI 改为按运行时棋盘尺寸生成连接表和 `2x2` 成方表，`8x8` 不再依赖 `14x14` 的硬编码开局形状。
- 修复 AI 返回非法着法的根因：对手着法数组误用、哈希表 key 缺少上下文、根着法返回前缺少真实棋盘复核。
- C# 执行 AI 着法前增加坐标、起点、终点和吃子列表校验，防止非法返回串破坏棋盘状态。
- 验证 `jqai.dll` 导出包含 `getAIMove` 与 `getAIMoveEx`。

## 2026-04-21：第一阶段三阶段基础对局落地

### 实现范围

- 新增规则模式：`传统基础` 与 `竞技化`，由主界面下拉框切换。
- 新增规则状态类型：`RuleMode`、`GameRuleConstants`、`AIState`，集中定义规则模式、飞子阈值和 AI 状态编码。
- 补齐飞子基础规则：当前行动方棋子数 `<= 14` 时，可选择任意己方棋子飞到任意空点。
- 保留 `iState == 3` 作为“成方补吃状态”，不再把它混称为“第三阶段飞子”。
- 竞技化模式新增飞子阶段保护规则：当对手已经具备飞子能力且当前方为强势方时，强势方跳吃不能以单吃结束，必须继续多吃。
- 主界面新增规则状态显示，显示当前规则模式、阶段、当前方和飞子能力。

### AI 与 DLL

- `getAIMove` 的 `state` 语义扩展为：
  - `1`：布局阶段
  - `2`：传统基础走子阶段
  - `3`：竞技化走子阶段
  - `4`：传统基础飞子能力
  - `5`：竞技化飞子能力
- `ai.cpp` 增加飞子走法生成：任意己方棋子可移动到任意空点。
- 竞技化单吃限制在 AI 合法走法生成层过滤，避免 AI 返回非法着法。
- 已回退 AI 递归层超时与布局超时兜底实验，恢复原有根层计时搜索行为，避免超时兜底破坏布局策略。
- 已回退“结束/停止”按钮的线程等待实验，恢复原有停止流程。
- `机机模式` 恢复原始双 DLL 隔离：第一 AI 导入 `jqai.dll`，第二 AI 导入 `jqai2.dll`。
- `jqai.vcxproj` 新增构建后复制步骤，将本次构建生成的新版 `jqai.dll` 同步复制为 `jqai2.dll`，避免第二 AI 使用旧规则 DLL。

### 构建环境

- WinForms 主程序目标框架迁移到 `.NET Framework 4.8.1`。
- `jqai.vcxproj` 工具集更新为 `v143`，Windows SDK 更新为 `10.0.26100.0`。
- 目标平台以 `x64` 为主。

- `Release|x64` 解决方案构建通过。
- `Debug|x64` 的 `jqai` 项目构建后成功同步 `jqai2.dll`。
