# 发布材料 v1

更新时间：2026-04-30

本文汇总 JavaFX 版阶段性交付材料。当前版本面向规则演示、论文答辩和继续开发验证，不宣称完整实现藏久棋全部传统规则。

## 版本能力

JavaFX 版当前已支持：

- 传统基础 `14x14` 与竞技化 `8x8` 双规则模式。
- 布子、走子、跑吃、连续跳吃、成方补吃和飞子基础移动。
- 基本阵型 v1：褡裢、双门褡裢、双门拉萨、三门拉萨。
- 特殊阵型 v1：枪、煞。
- 传统获胜阵型 v1：拉萨，以及弱势方飞子临界保门胜。
- `.jqj` 完整存档、旧文本棋盘读取、纯 Java AI、native AI 和 native AI + Java 校验。

仍未实现：

- 岚、三叉黑铁、恰、颂然等剩余特殊阵型。
- 八吉祥阵型识别与获胜。
- 十字飞子久、九子五久飞子久等飞子阵型。
- 固定棋形集合、让棋目标阵型、吃子数量和积分制等完整传统胜负体系。

## 运行与构建

开发运行：

```powershell
cd JQJava
mvn javafx:run
```

自动化测试：

```powershell
cd JQJava
mvn -q test
```

生成 jar 与运行时依赖：

```powershell
cd JQJava
mvn -q -DskipTests package
```

Windows app-image：

```powershell
cd JQJava
powershell -ExecutionPolicy Bypass -File scripts\package-windows.ps1
```

期望输出：

```text
JQJava\target\dist\windows\ZangJiuQi-Java
```

`target/` 下构建产物不提交到版本库。

## AI 对局说明

当前 AI 演示以规则层自动化测试和 Java AI 可生成合法着法为依据：

- `JavaAiClientTest` 覆盖纯 Java AI 在浅层可见局面中选择基本阵型、枪、煞和拉萨相关着法。
- native AI 可通过 Java 校验层复核返回着法；跨平台演示默认使用纯 Java AI。
- 本版本不提供胜率、Elo 或长期自我对局统计，避免把有限回归测试包装成实验结论。
