# 传统阵型模板资料 v1

更新时间：2026-05-06

本文记录 JavaFX 版传统阵型目标模板资料状态。已验证模板可用于传统 AI 启发；被前端选为传统获胜阵型时，也可用于补吃结算后的静态获胜扫描。模板资料不等同于成阵型吃规则触发。

## 录入原则

- 已验证模板才允许进入 Java catalog，并且必须有自动化测试覆盖。
- 未验证模板只能放在本文候选区，不能进入 Java catalog，也不能出现在前端获胜阵型选择或默认 AI 目标启发中。
- offset 坐标以模板左上角为 `(0,0)`，`file` 向右递增，`rank` 向下递增。
- 模板可单独声明变换方式；金鱼当前允许旋转与镜像。后续类似“右旋海螺”这种有方向语义的阵型，不应默认允许镜像。
- 新模板最少测试：完整形、一步可成、阻塞、旋转/镜像、边界。

## 当前口径

- 已有模板扫描底座：`PatternShape`、`PatternShapeScanner`、`PatternShapeScore`。
- 已验证并可作为传统获胜目标启用的模板包括拉萨和金鱼。
- 前端选择哪个传统获胜阵型，规则胜负和传统 AI 长期目标就只围绕该阵型；未选择的模板不影响当前对局。
- 八吉祥其他阵型、飞子阵型和让棋目标仍未实现规则识别、AI 目标和胜负判定。
